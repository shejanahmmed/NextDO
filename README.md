# NextDO

NextDO is a modern, minimalist to-do app designed to help you stay organized with style. Featuring a sleek dashboard design inspired by dot-matrix typography and grid aesthetics, it offers a premium user experience with smooth animations and intuitive gestures.

## Features
- **Minimalist Dashboard**: A clean, grid-based home screen with a large task counter and greeting.
- **Dot-Matrix Aesthetics**: Unique typography and design elements for a retro-futuristic look.
- **Gesture Controls**: Swipe left to delete tasks, swipe right to edit them.
- **Smart Reminders**: Set specific times for tasks and get timely standard notifications.
- **Customization**: Choose from various accent colors and background themes (including custom images).
- **Widgets**: Home screen widgets to see your upcoming tasks at a glance.
- **Recycle Bin**: Recover deleted tasks easily.

## Installation
You can download the latest APK from the **Releases** section of this repository. Just install it on your Android device and start using it right away.

## How It Works
1. **Add**: Tap the "+" button or "Add Task" tab to create a new task.
2. **Manage**: Swipe tasks to edit or delete them. Long-press for more options.
3. **Customize**: Go to Settings to change the theme, accent color, or background.
4. **Track**: View your progress with the dotted progress bar on the dashboard.
